# Bankruptcy Prediction System

## Project Overview
The Bankruptcy Prediction System is a Machine Learning project that predicts the likelihood of business bankruptcy based on financial and business-related input features. The project uses a trained machine learning model to generate predictions from user-provided inputs.

## Business Objective
The objective of this project is to help identify businesses that may be at risk of bankruptcy using data-driven predictions. Such predictions can support preliminary financial risk assessment and decision-making.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Streamlit
- Jupyter Notebook
- Machine Learning

## Project Files
- `EDA_Bankruptcy_Notebook (7).ipynb` — Exploratory Data Analysis and project notebook.
- `Bankruptcy_prevention_Dataset.csv` — Dataset used for the project.
- `Bankruptcy_Prevention.pkl` — Saved trained model.
- `train_model.py` — Script for model training.
- `app.py` — Streamlit application.

## Project Workflow
1. Load and explore the dataset.
2. Perform exploratory data analysis (EDA).
3. Prepare the data for machine learning.
4. Train a machine learning model.
5. Save the trained model.
6. Use the model to generate predictions through a Streamlit application.

## How to Run the Project Locally

### 1. Clone the Repository
```bash
git clone https://github.com/PritiHM/Bankruptcy-Prediction.git
cd Bankruptcy-Prediction
```

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Streamlit App
```bash
streamlit run app.py
```

## Disclaimer
This project is developed for educational and demonstration purposes. Predictions are model-based estimates and should not be treated as definitive financial or investment advice.
